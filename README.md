# Página romántica — guía rápida

La página funciona con tres archivos principales: `index.html`, `styles.css` y `script.js`. No necesita instalación ni herramientas especiales.

## Contenido personalizado

Esta versión ya contiene los nombres de Angélica y Juan, la fecha del 29 de mayo de 2025, el contador automático, las fotografías, la canción y los recuerdos proporcionados. No necesitas modificar el código.

La música no comienza sola: ella deberá tocar el botón “Música”. Esto respeta las reglas de los navegadores y le da control sobre el sonido.

## Publicar gratis en GitHub Pages

1. En GitHub, crea un repositorio nuevo y público; por ejemplo, `nuestra-historia`.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama **main**, la carpeta **/(root)** y pulsa **Save**.
6. Espera uno o dos minutos. GitHub mostrará la dirección pública, normalmente `https://TU-USUARIO.github.io/nuestra-historia/`.

Antes de compartirla, pruébala en el teléfono y revisa que las fotos y la canción aparezcan correctamente.
